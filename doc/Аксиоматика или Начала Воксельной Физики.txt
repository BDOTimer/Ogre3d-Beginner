1.0 Вводные?

    1.1 Есть Mир со статическими Объектами:
    
    Как туда эти объекты попали - это неважно.
    В контексте игры: Мир это колодец Well, а Объекты это Gems(жемчужины).
    Well представляет собой 2D матрицу(Array2D), ячейка которой содержит 1 Gem.
    Ячейка может быть и пустой.
    Т.е. мы имеем, что ячейка может находиться в двух состояниях 0/1.
    0/1 означает либо она ПУСТАЯ, либо содержит Gem.
    
    1.2 Есть Фигура(Figure), которая падает в колодце(Well):
    
    Фигура не статична - она имеет способность двигаться.
    Фигура состит из жестко связанного набора Gems.
    Каждый Gem имеет размер GemSizeFloat(в игре == 100.0f).
    У фигуры есть позиция в контесте непрерывного простанства.
    Начальное положение фигуры в Глобальном пространстве ==  {0.f, FH, 0.0f}
    Положение фигуры в каждый тик(deltaTime) времени == {xf, yf, 0.f}
    Получить его можно так: posFloat = figure.getPosition()
    Данная точка в пространстве posFloat принадлежит лево-нижнему углу фигуры.
    То есть позиция всей фигуры будем рассматривать относительно posFloat.
    
    ps: Это были вводные - теперь дальше ...
    
    
2.0 Что мы хотим?
    
    Нам нужно получить собтыите СТОЛКНОВЕНИЯ фигуры:
    - со стенками колодца(Well).
    - с уже упавшими жемчужинами(GemsWell).
    
    
    2.1 Столкновение со стенками:
        
    Задача отобразить Глобальную позицию фигуры на Array2D.
    Array2D - матрица имеет размеры W - по горизонтали и H по вертикали.
    Координаты стенки: 
        0 - левый край массива Array2D.
        W - правый край массива Array2D.
        H - высота Array2D.
        w, h - индексы содержимого Array2D.
    
    Очевидно, существует логическое требование:
        позиция фигуры на старте должно строго 
        совпадать с конкретной ячейкой Array2D.
        (! ... !)
        Т.е. тут нужно некоторое Соглашение:
        Если мы хотим, чтобы фигура появлялась строго над серединой колодца, то
        в массиве Array2D она должна позиционироваться, как W / 2.
        если W = 7, то позиция w фигуры в колодце = 3.
        по краям слева 0,1,2 и справа 4,5,6, а фигура висит над 3.
        
        Итого, наша конвертация будет выглядеть так:
        xi = int(x + GemSizeFloat * W) / GemSizeInt - W + W / 2;
        yi = int(x + GemSizeFloat * W) / GemSizeInt - W;
        
    ///------------------------------------------------------------------------|
    /// Стенд для тестирования преобразования float в индексы вокселей.
    ///------------------------------------------------------------------------:
    struct Test$f2i
    {   
        int   W{ 7};
        int   H{15};
        float GemSizeFloat{100.f};
        int   GemSizeInt  {int(GemSizeFloat)};

        int xf2i(float x)
        {   return int(x + GemSizeFloat * W) / GemSizeInt - W + W / 2;
        }

        int yf2i(float y)
        {   return int(y + GemSizeFloat * H) / GemSizeInt - H;
        }

        static void testX()
        {   Test$f2i tt;

            for(float xf; true; )
            {   std::cout << "float x: ";
                std::cin  >> xf;
                std::cout << std::format(
                              "   xf: {:6} ---> xi {:4}\n", xf, tt.xf2i(xf));
            }
        }

        static void testY()
        {   Test$f2i tt;

            for(float yf; true; )
            {   std::cout << "float y: ";
                std::cin  >> yf;
                std::cout << std::format(
                              "   yf: {:6} ---> yi: {:4}\n", yf, tt.yf2i(yf));
            }
        }
    };
    
    Искомое: если xf2i(xf) <  0, то мы имеем СТОЛКНОВЕНИЕ с левой стенокой.
             если xf2i(xf) >= W, то мы имеем СТОЛКНОВЕНИЕ с правой стенкой.
             если yf2i(yf) <  0, то мы имеем СТОЛКНОВЕНИЕ с дном.
             если yf2i(yf) >= H, то мы имеем жемчужину "улетевшую в небо".
    
    
    2.2 Столкновение с лежащим жемчугом в Well:
    
        w = xf2i(xf) - получаем индекс w столбца в Array2D
        h = yf2i(yf) - получаем индекс h строки  в Array2D
    
        далее, если Array2D[h][w].DataCell.isEmpty() == true,
        то ячейка является ПУСТОЙ - событие столкновения отсутствует.
    
    
3.0 Что делает фигура?

    Фигура может находиться в следующих состояниях:
        - покоится.
        - падать вниз y -= dtSpeed.
        - смещаться ВЛЕВО или ВПРАВО, но не одновременно.
        - одновременно она может ПАДАТЬ и смещаться (ВЛЕВО или ВПРАВО)
        
        
    3.1 Фигура падает:
    
    Что нужно будет нам сделать:
    
        Когда фигура падает мы имеем постоянное изменение y -= dtSpeed.
        На каждом тике или в каждом фрейме нужно проверить:
        
        h = yf2i(yf);
        Array2D[h][w].DataCell.isEmpty() == true
        если false, то имеем СТОЛКНОВЕНИЕ!
        
        Если оставить в таком виде, то мы имеем ПРОБЛЕМУ нахождения фигуры
        внутри лежащего объекта или выхода фигуры за стенки колодца(Well).
        
        Поэтму перед тем как сделать тик-смещения фигуры нужно сначало
        ПРОВЕРИТЬ, а есть ли место для этого смещения?!
        
        Тогда, если у нас пришла дельта скорости dtSpeed, то тогда делаем:
        
        h = yf2i(yf + dtSpeed);
        Array2D[h][w].DataCell.isEmpty() == true
        если false, то имеем СТОЛКНОВЕНИЕ!
        
        И далее, нужно прекратить падение, установив фигуру в текущей позиции:
        
        yf1 = yf2i(yf0) * GemSizeFloat;
        
        справедливо, если dtSpeed < GemSizeFloat;
        
        Но, мы получим БАГ(!), если dtSpeed >= GemSizeFloat;
        т.е. нам нужно КОНТРОЛИРОВТЬ максимальную скорость для dtSpeed:
        
        dtSpeed = dtSpeed < GemSizeFloat ? dtSpeed : GemSizeFloat - 1;
        
        
    3.2 Фигура смещается ВЛЕВО/ВПРАВО:
        Всё тоже самое, что и для 3.1, казалось бы ...
        
    
    3.3 Но рассмотрим такую ситуацию: Фигура падает и мы делаем сдвиг:
        
        Проблема в том, что фигура имеем размер,
        а мы её рассмотрели выше, как точку.
        
        Смещение фигуры по индексам не происходит мгновенно,
        За период времени, пока происходит смещение на 1 индекс
        фигура находиться сразу в нескольких вокселях:
        один она ещё не полностью покинула, а в другой воксель он ещё
        полностью прибыла.
        
        Отсюда делаем вывод:
        Фигурный воксель должен иметь 4 сенсора:
        
        sensor1   sensor2  
        q---------------p
        |               |
        |               |
        |               |
        |               |
        |               |
        d---------------b
        sensor0   sensor3
        
        sensor0 имеет наши координаты { xf, yf }.
        
        Например, если фигура ПАДАЕТ, и мы решаем двинуть её ВПРАВО,
        то на припятствие ВНИЗ, нужно проверить:
        
        ВНИЗ:[d, b]
        
        isCollision({xf2i(xf),                yf2i(yf)}) && 
        isCollision({xf2i(xf + GemSizeFloat), yf2i(yf)})
        
        для ВЛЕВО:[d, p]
        
        isCollision({xf2i(xf), yf2i(yf)               }) &&
        isCollision({xf2i(xf), yf2i(yf) + GemSizeFloat})
        
        для ВПРАВО:[d, q]
        
        isCollision({xf2i(xf) + GemSizeFloat, yf2i(yf) + GemSizeFloat}) &&
        isCollision({xf2i(xf) + GemSizeFloat, yf2i(yf) + GemSizeFloat})
        
        
4.0 И что нам понадобиться в программе игры Columns?

    - Модуль Коллизеры(Collisions)
    - Модуль-Котроллер(Stepper) для движение на заданную дистанцию.
    - Stepper использует Collisions.
    
    4.1 struct Collisions;
        
    
    4.2 struct Stepper;
        Почему такое название?
        Дистанция на которую мы можем и на кото нужно смещать 
        ВСЕГДА КРАТНО GemSizeFloat!
        Т.е. наша фигура как бы шагает на шаг GemSizeFloat,
        а в Array2D на 1 индекс.
